Install in four steps

  1. Download the free 3-day trial from the download section on your Windows PC.
  2. Right-click the zip, choose Extract All, and extract it to your Desktop.
  3. Open the folder and double-click Start-Keepsake-Photos.bat.
  4. Use every feature free for 3 days, then enter your activation code to unlock everything.

Common questions

Windows says it protected my PC

SmartScreen can show this for new apps. If you downloaded Keepsake Photos from this site, choose More info, then Run anyway.

Nothing happens when I double-click the file inside the zip

Extract the zip first. Apps can’t run from inside a compressed folder.

I bought an activation code but haven’t received it

Check your spam or promotions folder for an email from us. If it isn’t there, email support@keepsakephotos.net with your PayPal or Square receipt.

My activation code is not accepted

Copy and paste the code exactly as it appears in your email. Activation codes begin with OCPY-. If it still isn’t accepted, write to us with your receipt.

Moving to a new PC

Your activation code covers the number of computers in your edition: Home 1, Family 3, Studio 5. Email us if you need to move a license to a new computer.
